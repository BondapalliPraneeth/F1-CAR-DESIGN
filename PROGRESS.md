# ApexVision 3D — build progress

## Done
- **Backend** (FastAPI): simulation core, 20-component catalogue, 11 scenarios, 11-table DB with Alembic, all `/api/v1` endpoints, AI (6 tools, Gemini/OpenAI + offline engine + numeric verifier), reports (MD/HTML/JSON) and CSV. 44 pytest tests pass; ruff is clean.
- **3D asset**: `assets/tools/generate_car.py` produces `frontend/public/models/apexvision_av1.glb` (20 components, 119 parts, ~62k triangles) plus its parts manifest.
- **Frontend** (React/TS/Vite/Tailwind/R3F/Plotly/zustand):
  - viewer: select, hover, isolate, hide, explode, X-ray, camera presets, PNG, kinematic damage visuals
  - per-component panels with damage controls
  - 13-chart dashboard
  - AI chat, assumptions editor, history, save & report
  - tsc is clean; 17 vitest tests pass; build passes
- **Tests**: Playwright e2e suite (8 tests) in `frontend/e2e`.
- **Infra**: docker-compose, both Dockerfiles, `vercel.json`, `render.yaml`, GitHub Actions CI.
- **Docs**: README, `docs/simulation_methodology.md`, `docs/component_specifications.md` (generated by `backend/scripts/gen_component_docs.py`), `docs/3d_asset_guide.md`.

## Not yet verified (blocked locally)
- **Visual check of the 3D viewer and the e2e run.** Avast WebShield returns HTTP 403 for the Vite dev bundle
  `localhost:5173/node_modules/.vite/deps/@react-three_drei.js` ("known threat"). This is almost certainly a false positive on the
  minified drei bundle. To unblock: add a WebShield exception for `localhost`, or test the production build (`npm run build && npx vite preview`).
- **Docker image builds.** The Docker Desktop engine was not running. CI builds both images on every push.

## Remaining (needs the user)
1. Push to a GitHub repo (or run `gh auth login`) so CI can run.
2. Deploy: Neon DB → Render (Blueprint from `render.yaml`) → Vercel (root `frontend`). See the README.
3. Optional: add `GEMINI_API_KEY` or `OPENAI_API_KEY` in Render. Without one, the offline engine is used.

## Run locally
```
cd backend && PYTHONPATH=. .venv/Scripts/python.exe -m uvicorn app.main:app --reload
cd frontend && npm run dev
```
